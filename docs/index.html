Quick Start

Run your first sample in minutes

Clone the repository, browse to an example, and apply the manifest to your EKS cluster. Each example folder contains a README.md with prerequisites and step-by-step instructions.

terminal
# 1. Clone the repo git clone https://github.com/aws-samples/aws-eks-samples.git cd aws-eks-samples # 2. Browse an example ls examples/kubernetes/ # 3. Apply the manifest kubectl apply -f examples/kubernetes/network-policies/ # 4. Or create a cluster with eksctl eksctl create cluster -f examples/eksctl/how-to-eks-auto-mode/eks-auto.yaml
⚠️

For learning and testing only

These examples are not production-ready. Always follow Amazon EKS Security Best Practices before deploying to production.
